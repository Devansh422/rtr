# Python dependencies for the Vercel serverless function (api/index.py).
#
# A byte-identical copy lives at api/requirements.txt as a safety net in case
# Vercel's builder prefers a requirements.txt co-located with the function over
# this project-root one. If you change one, change both.
#
# Pins are carried over from backend/requirements.txt, which is a full freeze of
# the development container. Only what the app actually imports at RUNTIME is
# listed here: the serverless bundle has a hard size limit, so dev/test/lint
# tooling (pytest, black, flake8, mypy, isort, alembic) and unused SDKs (boto3,
# google-*, openai, pandas, numpy, stripe, ...) are deliberately left out.
#
# Alembic in particular is absent on purpose: migrations are applied from CI or
# a developer machine (`cd backend && alembic upgrade head`), never by the
# serverless function itself. A function that races to migrate its own schema on
# cold start is how you get a half-migrated database.
