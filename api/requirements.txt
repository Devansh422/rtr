# Python dependencies for the Vercel serverless function (api/index.py).
#
# DUPLICATE of /requirements.txt at the repo root. Vercel's exact requirements.txt
# discovery order for a mixed Node+Python monorepo isn't documented precisely, so
# this copy exists as a safety net in case the builder prefers a file co-located
# with the function over the project root one. If you change one, change both --
# they must stay byte-identical.
#
# Pins are carried over from backend/requirements.txt, which is a full freeze of
# the development container. Only what backend/server.py actually imports (plus
# the runtime bits Mongo Atlas needs) is listed here: the serverless bundle has a
# hard size limit, so dev/test/lint tooling (pytest, black, flake8, mypy, isort)
# and unused SDKs (boto3, google-*, openai, litellm, pandas, numpy, stripe, ...)
# are deliberately left out.
